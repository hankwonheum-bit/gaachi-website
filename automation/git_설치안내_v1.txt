=========================================================
 Git for Windows 설치 안내 (사례 자동 게시용)
=========================================================

[왜 필요한가요?]

지금 이 컴퓨터에는 GitHub Desktop 만 있고, 명령줄에서 쓰는 git 이
설치되어 있지 않습니다. 자동 게시 프로그램은 명령줄 git 으로
"커밋 + 푸시" 를 하기 때문에, git 이 없으면 사례 페이지를 만들어
놓기만 하고 홈페이지에는 올리지 못합니다.

(참고: git 이 없어도 자동화가 멈추지는 않습니다. 사례 페이지와
 index.html, sitemap.xml 수정까지는 그대로 진행되고, 마지막
 "홈페이지에 올리는 단계"만 건너뜁니다. 그때는 GitHub Desktop 을
 열고 Push 를 누르면 그대로 게시됩니다.)

아래대로 한 번만 설치하면 그 뒤로는 모든 과정이 자동으로 끝납니다.


---------------------------------------------------------
[설치 방법] — 5분이면 끝납니다
---------------------------------------------------------

1. 아래 주소를 인터넷 창에 넣고 들어갑니다.

       https://git-scm.com/download/win

2. "64-bit Git for Windows Setup" 을 눌러 설치 파일을 받습니다.
   (자동으로 다운로드가 시작되기도 합니다.)

3. 받은 파일을 두 번 눌러 실행합니다.
   "이 앱이 장치를 변경하도록 허용하시겠어요?" 가 뜨면 [예] 를 누릅니다.

4. ★ 설치 화면이 여러 번 나오는데, 전부 그냥 [Next] 를 누르시면 됩니다.
   기본 설정이 우리에게 딱 맞습니다. 아무것도 바꾸지 마세요.

   다만 아래 두 가지만 지나갈 때 체크가 되어 있는지 눈으로 확인해 주세요.
   (기본값이 이미 체크되어 있으니 보통은 그냥 Next 로 넘기면 됩니다.)

   (1) "Adjusting your PATH environment" 화면
       -> 가운데 항목
          "Git from the command line and also from 3rd-party software"
          가 선택되어 있어야 합니다.
       -> 이 항목이 바로 git 을 PATH 에 등록해 주는 설정입니다.
          이게 선택되어야 자동 게시 프로그램이 git 을 찾을 수 있습니다.

   (2) "Select Components" 화면
       -> "Git Credential Manager" 가 체크되어 있어야 합니다.
       -> GitHub 로그인 정보를 기억해 주는 기능입니다.
          이게 있어야 푸시할 때 매번 로그인하지 않습니다.

5. 마지막에 [Install] 을 누르고, 끝나면 [Finish] 를 누릅니다.

6. ★ 설치가 끝나면 열려 있던 검은 창(명령 프롬프트)을 모두 닫고,
   automation\점검_v1.bat 을 다시 실행해 주세요.
   (이미 열려 있던 창은 새 PATH 를 모르기 때문에 꼭 다시 실행해야 합니다.)

   [2/5] Git 확인 에 초록불처럼 [정상] 이 뜨면 성공입니다.


---------------------------------------------------------
[설치했는데도 "git 을 찾을 수 없습니다" 가 뜬다면]
---------------------------------------------------------

수동으로 경로를 알려 줄 수 있습니다. (비상용 탈출구)

   automation\config\git_path_v1.txt

이 파일을 메모장으로 열고, git.exe 의 전체 경로를 한 줄로 적은 뒤
저장하세요. 예:

   C:\Program Files\Git\cmd\git.exe

  - 한 줄만 적으면 됩니다. 따옴표는 있어도 되고 없어도 됩니다.
  - 맨 앞이 # 으로 시작하는 줄은 설명글로 보고 무시합니다.
  - 파일이 비어 있거나 # 줄만 있으면 "설정 안 함" 으로 보고
    프로그램이 알아서 git 을 찾습니다. (기본 상태)

저장한 뒤 점검_v1.bat 을 다시 실행하세요.


---------------------------------------------------------
[프로그램이 git 을 찾는 순서]
---------------------------------------------------------

1. automation\config\git_path_v1.txt 에 적힌 경로   (수동 지정)
2. PATH 에 등록된 git                              (Git for Windows 설치 시)
3. GitHub Desktop 에 들어 있는 git                  (임시방편)
4. C:\Program Files\Git\ 아래의 git
5. 내 계정 폴더 안에 설치된 git

3번(GitHub Desktop 내장 git)으로 동작하는 경우, 점검 화면에 [주의]
표시가 뜹니다. GitHub Desktop 을 업데이트하면 폴더 이름이 바뀌어
어느 날 갑자기 안 될 수 있으니, 되도록 위의 설치를 해 주세요.


---------------------------------------------------------
[git 없이 사례가 준비된 날에는]
---------------------------------------------------------

automation\state\published_log.tsv 의 맨 뒷칸에

   GIT_NOT_FOUND / 페이지는 내 컴퓨터에 준비 완료 - 아직 홈페이지에
   게시되지 않았습니다. GitHub Desktop 을 열고 Push 를 눌러 주시면
   그때 홈페이지에 반영됩니다.

라고 적힙니다. 이 줄이 보이면 GitHub Desktop 을 열고 Push 를
한 번만 눌러 주세요. 그러면 그 사례가 홈페이지에 올라갑니다.
