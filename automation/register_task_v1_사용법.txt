가치앤같이 사례 자동 게시 — 작업 스케줄러 등록 사용법 (v1)
==========================================================

[1] 무엇을 하는 스크립트인가요?
    automation\register_task_v1.ps1 을 실행하면 윈도우 "작업 스케줄러"에
    다음 이름의 자동 실행 작업이 등록됩니다.

        가치앤같이_사례자동게시

    등록 후에는
      · PC 로그온 3분 뒤
      · 매일 오전 9시
    두 시점에 자동으로 실행되며, automation\queue 폴더에 대기 중인
    사례 HTML 중 가장 앞 번호 1건을 홈페이지에 게시합니다.
    (하루 1건만 게시되고, 대기열이 비어 있으면 아무 일도 하지 않습니다.)


[2] 등록 방법 — 둘 중 편한 방법을 쓰세요.

  방법 A) 마우스로
    1) 파일 탐색기에서 다음 폴더를 엽니다.
       C:\Users\user\Documents\GitHub\gaachi-website\automation
    2) register_task_v1.ps1 파일을 마우스 오른쪽 클릭
    3) "PowerShell로 실행" 클릭
    4) 파란 글씨로 "등록 완료!" 가 보이면 성공입니다.
       ※ 실행 정책 경고가 뜨면 방법 B를 사용하세요.

  방법 B) 명령으로 (권장)
    1) 저장소 폴더에서 Shift + 마우스 오른쪽 클릭
       → "여기에 PowerShell 창 열기" 클릭
    2) 아래 한 줄을 그대로 붙여넣고 Enter

       powershell -ExecutionPolicy Bypass -File .\automation\register_task_v1.ps1

    3) "등록 완료!" 메시지 확인


[3] 제대로 등록됐는지 확인하기
    1) 윈도우 검색창에 "작업 스케줄러" 입력 → 실행
       (또는 Win + R → taskschd.msc → Enter)
    2) 왼쪽 트리에서 "작업 스케줄러 라이브러리" 클릭
    3) 가운데 목록에서 "가치앤같이_사례자동게시" 를 찾습니다.
    4) 더블클릭하면
         · [트리거] 탭 : "로그온할 때 - 3분 지연", "매일 오전 9:00:00" 2개
         · [동작]  탭 : wscript.exe ... run_hidden_v1.vbs
         · [설정]  탭 : "예약 시작 시간을 놓친 경우 가능한 한 빨리 작업 시작" 체크
       위 내용이 보이면 정상입니다.
    5) 목록에서 오른쪽 클릭 → "실행" 을 누르면 즉시 한 번 시험 실행됩니다.


[4] 실행 결과 확인
    automation\logs 폴더의 아래 두 파일을 메모장으로 열어 보세요.
      · run-YYYYMMDD.log      : 배치 실행 기록 (python 호출/종료 코드)
      · publish-YYYYMMDD.log  : 게시 상세 기록 (검증/백업/커밋/푸시)
    게시 이력 전체는 automation\state\published_log.tsv 에 한 줄씩 쌓입니다.


[5] 잠시 멈추고 싶을 때
    · 작업 스케줄러에서 "가치앤같이_사례자동게시" 오른쪽 클릭 → "사용 안 함"
    · 또는 automation\queue 폴더 이름을 queue_off 로 바꾸면
      대기열이 비어 있는 것으로 처리되어 아무것도 게시되지 않습니다.
    · 작업 자체를 완전히 삭제하려면:

       powershell -ExecutionPolicy Bypass -File .\automation\register_task_v1.ps1 -Remove


[6] 실제 게시 없이 점검만 하기 (안전, 파일을 전혀 건드리지 않음)

       cd C:\Users\user\Documents\GitHub\gaachi-website
       python automation\publish_case_v1.py --dry-run
