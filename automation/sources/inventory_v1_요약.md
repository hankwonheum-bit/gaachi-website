## 6. 게시 순서(우선순위) 규칙

**Tier(대분류) → 다양성 인터리빙** 2단계.

1. **Tier 1 (seq 1~33)** — 상속 / 증여 / 세무서 제출. 회사 타깃 키워드.
2. **Tier 2 (seq 34~53)** — 담보 / 경매 / 시가참고.
3. **Tier 3 (seq 54~68)** — 보상 / 자산재평가 / 임대료산정 / 국공유재산 / 기계기구 / 법인 / 기타.

각 Tier 내부에서는 같은 지역·같은 물건종류가 연달아 나오지 않도록 아래 점수가 가장 높은 건을 순서대로 뽑는 그리디 방식을 사용했습니다.

```
점수 = (직전 행과 구/시가 다르면 +4)
     + (직전 행과 물건종류가 다르면 +2)
     + (두 칸 앞 행과도 구/시가 다르면 +1)
동점이면 감정평가액이 큰 건 우선 → file_id 사전순
```

- **+4 (지역)**: 강남구 아파트가 5건 연속 나오는 것을 막고, 검색 쿼리 공간(「OO구 감정평가」)을 넓게 덮습니다.
- **+2 (물건종류)**: 아파트-근린생활시설-토지-다가구처럼 물건종류도 번갈아 나오게 합니다.
- **+1 (2칸 전 지역)**: A-B-A-B 진동을 막아 3건 단위로도 지역이 겹치지 않게 합니다.
- **동점 시 고액 우선**: 고가 물건이 검색 노출·문의 전환에 유리하므로 앞쪽에 배치합니다.

결과적으로 Tier 1 상위 15건은 김해-서대문-강남-김해-서대문-송파-강남-서초-마포-송파-강동-강남-마포-서초-강남 순으로 지역이 분산되고, 물건종류도 근린생활시설/아파트/주택/상가/토지가 교대로 나옵니다.
