# 사례 초안 검토 체크리스트 v1 — 승인 전에 1분만 보시면 됩니다

> 최초 **10건**은 사람이 승인해야 게시됩니다. 10건을 승인하면 그 뒤로는 자동 게시로 전환됩니다.
> 아래 항목은 **위험이 큰 순서**로 정렬돼 있습니다. ①②를 통과하지 못하면 나머지는 볼 필요 없이 반려하십시오.

---

## 준비 — 초안 열기와 승인 실행

**1) 초안을 브라우저로 봅니다**

`C:\Users\user\Documents\GitHub\gaachi-website\automation\review\` 폴더를 열고
`NNN_슬러그.html` 파일을 **더블클릭**하면 기본 브라우저에서 완성된 페이지가 그대로 보입니다.
(인터넷에 올라간 상태가 아니라 내 PC 파일을 보는 것이라 안전합니다.)

**2) 승인/반려**

`automation\승인_v1.bat` 을 **더블클릭** → 대기 목록이 뜹니다 → 승인할 **번호**를 입력하고 Enter.
승인되면 파일이 `automation\queue\` 로 옮겨지고, 다음 자동 게시 실행 때 사이트에 올라갑니다.

반려는 PowerShell 에서(폴더에서 Shift + 우클릭 → "여기서 PowerShell 창 열기"):

```
python automation\approve_v1.py                                   # 목록 보기
python automation\approve_v1.py --reject 1 --reason "감정평가액 오기"
python automation\approve_v1.py --status                          # 승인 누적 확인
```

반려된 초안은 `automation\rejected\` 로 옮겨지고 사유 파일이 함께 남습니다. **삭제되지 않습니다.**
승인 카운터는 승인할 때만 올라갑니다(반려는 올라가지 않습니다).

## ① 마스킹 — 개인정보가 남아 있지 않은가  ★최우선

페이지에서 **Ctrl+F** 로 아래를 검색해 보십시오. 하나라도 나오면 **즉시 반려**입니다.

- [ ] **사람 이름이 없다** — 의뢰인·소유자·신청인 성명. 원본 PDF 파일명에 들어 있던 이름도 포함
      (예: `HQ20255-10002 날인본 **최상기** 총괄.pdf` → 페이지에 `최상기` 가 있으면 반려)
- [ ] **호수가 가려져 있다** — `███호` 로 표시. `101호`, `1503호` 처럼 실제 호수가 보이면 반려
- [ ] **본건 층수가 가려져 있다** — `제█층`
- [ ] **지번이 없다** — 주소가 `서울 강동구 성내동` 처럼 **동까지만**. `성내동 123-4` 는 반려
- [ ] **보고서 번호가 없다** — `HQ2025x-xxxxx` 형식의 번호가 보이면 반려
- [ ] **감정평가전례 표**: 기준시점이 `2025년` 처럼 **연도만**, 목적 칸은 `—`
- [ ] **비교사례 표**: 층수가 지워져 있고 동/호만 (`104동 ███`)

> 게시된 뒤에 지워도 검색엔진·AI 캐시에 남습니다. 이 항목만큼은 의심스러우면 무조건 반려하십시오.

## ② 숫자 — 원본 감정평가서와 일치하는가  ★두 번째로 위험

원본 PDF(`바탕화면 > 홈페이지 개설 > 신규홈페이지 > 감정서 샘플`)의 **감정평가표** 페이지를 열어 놓고 대조합니다.

- [ ] **최종 감정평가액** — 원 단위 전액이 한 자리도 틀리지 않는가 (페이지 상단 큰 숫자 + 본문 + FAQ 답변, **3곳이 모두 같은 값**인가)
- [ ] **기준시점** — 연·월·일이 맞는가 (페이지 곳곳에 반복되므로 전부 같은 날짜인가)
- [ ] **면적** — 토지면적 / 건물 연면적 / 전유·대지권 면적이 ㎡ 소수점까지 맞는가
- [ ] **결정단가(원/㎡)** × 면적 = 토지가액이 **계산상 맞는가** (암산으로 자릿수만이라도)
- [ ] **토지가액 + 건물가액 = 최종 감정평가액** 인가
- [ ] **사용승인일·경과연수**가 맞는가

> 틀린 평가액이 올라가는 것이 이 자동화의 최악의 사고입니다. 숫자 하나라도 다르면 반려하고 사유에 정확한 값을 적어 주십시오.

## ③ 수수료 — 금액 언급이 전혀 없는가

- [ ] `수수료`, `보수`, `비용`, `○○만원` 같은 **가격 관련 표현이 한 군데도 없다**
- [ ] 문의 안내가 "사전 검토 후 일정과 절차를 안내해 드립니다" 수준으로만 되어 있다

(검증 스크립트가 1차로 막지만, 변형 표현은 사람이 봐야 잡힙니다.)

## ④ 평가방법 설명이 조문과 맞는가

- [ ] **집합건물**(아파트·오피스텔·구분상가)인데 토지·건물을 따로 평가했다고 쓰여 있지 않은가
      → 집합건물은 「감정평가에 관한 규칙」 **제16조** 로 **일괄 거래사례비교법**
- [ ] **토지·건물 복합부동산**인데 조문이 뒤바뀌지 않았는가
      → 토지 **제14조**(공시지가기준법), 건물 **제15조**(원가법)
- [ ] 생략한 평가방법(예: 수익환원법)에 **생략 사유**가 적혀 있는가
- [ ] 시점수정에 쓴 **지수명이 실제로 사용한 지수**인가 (없는 지수를 지어내지 않았는가)
- [ ] **상속/증여 평가기간 표기가 정확한가** —
      상속 = 전 6개월 ~ 후 6개월 / 증여 = 전 6개월 ~ 후 3개월
      ("상속·증여 모두 전후 6개월" 이라고 쓰여 있으면 반려)
- [ ] 인용한 조문 번호가 제14·15·16조, 상증세법 제60·61조, 시행령 제49조 범위 안인가

## ⑤ 제목·URL 슬러그

- [ ] 페이지 제목이 `지역 + 물건 + 목적 감정평가 사례` 형식이고 지번·호수가 없는가
- [ ] 파일명 슬러그(`NNN_슬러그.html` 의 슬러그 부분)가 영문 소문자+하이픈이고, 내용과 맞는가
- [ ] `cases/` 에 이미 있는 이름과 겹치지 않는가
      (겹치면 게시 스크립트가 `-v2` 를 붙여 버려 주소가 지저분해집니다)
- [ ] 카드 정보(`.meta.tsv`)의 지역·기준시점·평가액이 페이지 내용과 같은가

## ⑥ FAQ 답변이 사실인가

- [ ] Q1 답변의 **평가액·기준시점·면적**이 본문과 같은 값인가
- [ ] Q2 답변의 **평가방법·조문**이 ④와 모순되지 않는가
- [ ] Q3 답변의 **평가기간(6개월/3개월)** 표기가 정확한가

- [ ] 클릭했을 때 FAQ 가 정상적으로 펼쳐지는가

## 반려 사유는 구체적으로

반려 사유는 다음 초안 품질을 바로 올리는 유일한 입력입니다. 짧아도 **무엇이 틀렸고 정답이 무엇인지**를 적어 주십시오.

```
python automation\approve_v1.py --reject 1 --reason "최종평가액 1,577,010,440원이 맞는데 1,577,010,400원으로 적힘. 3곳 모두 수정 필요"
python automation\approve_v1.py --reject 2 --reason "비교사례 표에 층수(3층)가 남아 있음. 동/호만 남기고 삭제"
```

## 승인 진행 상황

```
python automation\approve_v1.py --status
```

- 승인 누적이 **10건**이 되면 다음 날부터 초안이 `automation\review\` 를 거치지 않고
  `automation\queue\` 로 바로 들어가 **승인 없이 게시**됩니다.
- 자동 전환 뒤에도 게시된 페이지는 `automation\state\published_log.tsv` 에 모두 기록되며,
  문제가 있으면 `cases/` 의 해당 파일을 수정하면 됩니다.
- 자동 전환을 **미루고 싶으면** `automation\state\approval_counter_v1.txt` 의 숫자를 낮추면 됩니다
  (예: `9` 로 되돌리면 다시 승인 단계가 됩니다).
