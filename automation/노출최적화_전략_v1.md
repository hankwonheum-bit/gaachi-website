## 1. 네이버 (국내 최대 · 최우선)

**현재 상태: 서치어드바이저 미등록 — 사실상 네이버 노출 0에 가까움. 최우선 과제.**

### 해야 할 일 (소유자 작업)
1. `searchadvisor.naver.com` → 사이트 등록 → 소유확인(HTML 파일 업로드 또는 메타태그)
2. **sitemap.xml 제출** + **robots.txt 확인**(이미 `User-agent: Yeti / Allow: /` 설정돼 있음)
3. 수집 현황·색인 상태·사이트 구조를 주기적으로 확인

### 2026년 네이버 검색 로직 (업계 정리 기준 — 1차 출처 아님, 참고용)
- **C-Rank** — 출처의 신뢰도. 맥락(Context)·내용(Content)·연결(Chain, 내부링크). → 사례 간 `REL` 상호링크와 허브 페이지가 여기에 기여.
- **D.I.A. / D.I.A.+** — 주제 적합도, **경험 정보**, 정보 충실성, 독창성. → 실제 수행 사례를 1차 데이터로 쓰는 우리 구조가 유리.
- **AI 브리핑(AiRSearch)** — 정보성 질의의 상당 부분에 AI 요약이 노출된다는 보도. 구조화·요약형 콘텐츠가 유리.

### 우리가 가진 강점과 공백
- 강점: **1차 데이터(실제 감정평가 사례)** — 번역·짜깁기가 아님. D.I.A.가 평가하는 "경험 정보"에 정확히 해당.
- 공백: 네이버는 **자사 서비스(블로그·포스트·지식iN·스마트플레이스) 가중치가 높다.** 웹사이트만으로는 한계.
  → 스마트플레이스 등록(§3)과 지식iN 답변이 실질적 보완책. **소유자 판단 필요.**

## 2. 다음 / 카카오

- **다음 검색등록**(`register.search.daum.net`)에 사이트 등록 — 네이버보다 절차가 단순.
- 다음은 웹문서 색인에 robots.txt·sitemap을 따르며, 우리 robots.txt에 `User-agent: Daum / Allow: /` 이미 있음.
- 네이트는 다음 검색결과를 일부 사용 → 다음 등록이 네이트 노출로 이어짐.

## 3. 외부 프로필 (`sameAs`) — **현재 0개. 구조적 약점.**

AI 엔진은 자사 콘텐츠보다 **외부 언급(earned media)** 에 체계적으로 더 큰 가중치를 둔다.
`index.html`의 Organization 스키마에 `sameAs`가 **하나도 없어** 엔터티가 외부와 연결되지 않는다.

순서(소유자 작업): ① 네이버 스마트플레이스 ② Google 비즈니스 프로필 ③ 한국감정평가사협회 법인 페이지
→ **상호·주소·전화를 홈페이지와 글자 단위로 동일하게** 맞춘 뒤 `sameAs`에 추가.

## 4. AI 검색 인용 (GEO) — 이미 잘 돼 있는 부분과 남은 것

### 이미 확보
- robots.txt에서 GPTBot·OAI-SearchBot·ClaudeBot·PerplexityBot·Google-Extended·Bingbot·Yeti·Daum 전부 `Allow`
- `Content-Signal: search=yes, ai-input=yes, ai-train=yes`
- FAQPage·Article·BreadcrumbList·RealEstateListing 구조화 데이터, llms.txt, RSS

### 남은 것
| 우선 | 항목 | 내용 |
|------|------|------|
| **상** | **Bing Webmaster Tools 등록** | ChatGPT 검색은 Bing 인덱스 의존도가 높다 |
| **상** | **저자(Person) 스키마 신설** | GEO에서 "전문가 신원·자격"이 출처 권위 평가의 핵심. 현재 사이트에 Person 스키마 **0개**. 개별 사건 담당자 대신 **법인 대표 평가사 소개 페이지**로 해결(공개범위 규칙과 충돌 없음) |
| 중 | 사례별 TL;DR 강화 | 이미 `lead-answer`가 있음. 요약 섹션과 중복되지 않게 유지 |
| 중 | 허브 페이지 노출 | `cases/index.html` 이 2026-09-30에야 저장소에 반영됨. sitemap 등록·홈 링크 필요 |
