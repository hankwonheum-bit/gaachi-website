# Step 1 — 대상 선정

`automation/sources/inventory_v1.tsv` 의 컬럼 순서(1-base)는 다음과 같습니다. **컬럼 번호를 착각하지 마십시오.**

```
1 seq   2 file_id   3 purpose   4 region   5 dong   6 prop_type
7 base_date   8 value_krw   9 methods   10 status   11 src_path   12 notes
```

→ `status` 는 **10번**, `notes` 는 **12번**입니다. (`$9` 는 `methods` 입니다.)

**선정 규칙**: `status == PENDING` 이고 `notes` 에 `부적합` / `UNSUITABLE` 이 없는 행 중 `seq` 가 가장 작은 1건.

```bash
awk -F'\t' 'NR>1 && $10=="PENDING" && $12 !~ /부적합/ && $12 !~ /UNSUITABLE/ {print; exit}' \
  "$HOME/mnt/gaachi-website/automation/sources/inventory_v1.tsv"
```

- 대상이 없으면 "게시 가능한 PENDING 사례가 없습니다" 라고 보고하고 종료합니다.
- `notes` 에 `미추출:` 항목이 있으면 **PDF 에서 직접 확인해야 하는 값**입니다.
  확인이 불가능하면 건너뛰지 말고 **중단하고 사용자에게 보고**하십시오.

# Step 2 — PDF 판독

**원본 PDF 는 전부 스캔 이미지입니다. 텍스트 레이어가 없습니다.** `pdftotext` 는 빈 결과를 냅니다.

## 2-A. 권장 경로 — 이미지로 변환해 Read 툴로 눈으로 읽기 ★

**감정평가표와 비교사례 표는 반드시 이 경로로 읽으십시오.** OCR 은 표의 자릿수·쉼표·㎡ 단위를
일상적으로 망가뜨립니다.

1. `mcp__remote-devices__device_stage_files` 에 PDF 절대경로를 넘겨 `/mnt/user-data/uploads/...` 로 복사합니다.
2. 그 경로를 **Read 툴**로 `pages: "1-6"` 처럼 지정해 직접 읽습니다(한 번에 최대 20페이지).
3. 표는 화면에 보이는 대로 옮겨 적고, 숫자는 한 자리씩 대조합니다.

```bash
mkdir -p /tmp/pg && pdftoppm -r 150 -gray -f 1 -l 6 -png \
  "$HOME/mnt/홈페이지 개설/신규홈페이지/감정서 샘플/<파일명>.pdf" /tmp/pg/p && ls -la /tmp/pg
```

## 2-B. 보조 경로 — OCR (검색·위치 파악용, 숫자 확정용 아님)

```bash
ls /tmp/tessdata/kor.traineddata 2>/dev/null || { \
  mkdir -p /tmp/tessdata && \
  curl -L -o /tmp/tessdata/kor.traineddata \
    https://github.com/tesseract-ocr/tessdata/raw/main/kor.traineddata ; }
TESSDATA_PREFIX=/tmp/tessdata tesseract --list-langs

mkdir -p /tmp/pg && pdftoppm -r 150 -gray -f 1 -l 6 -png \
  "$HOME/mnt/홈페이지 개설/신규홈페이지/감정서 샘플/<파일명>.pdf" /tmp/pg/p

for f in /tmp/pg/p-*.png; do
  echo "===== $f ====="
  TESSDATA_PREFIX=/tmp/tessdata tesseract "$f" stdout -l kor --psm 6 2>/dev/null
done
```

**OCR 결과의 숫자는 그 자체로 신뢰하지 않습니다.** 값은 반드시 2-A 의 페이지 이미지로 확정합니다.

## 2-C. 숫자 이중 확인 (예외 없음)

- 최종 감정평가액 (원 단위 전액)
- 기준시점 (**연도**. 월·일은 페이지에 쓰지 않지만 평가기간 판단을 위해 읽습니다)
- 감정평가서 작성일 (표지 기재일 — **페이지에 월·일까지 씁니다**)
- 토지면적 / 건물 연면적 / 전유면적 / 공용면적 / 대지권면적 (㎡)
- **결정단가(산정단가)** (원/㎡) ← v3 지침에서는 이 값이 산정과정의 **시작점**입니다
- 산출금액(결정단가 × 면적)과 최종 감정평가액의 차이(절사액)
- 사용승인일

**사정보정치·시점수정률은 페이지에 쓰지 않으므로 초안용으로 수집하지 않습니다.**
(감정평가서에서 결정단가가 제대로 읽혔는지 교차 확인하는 용도로만 보고, 초안 어디에도 옮기지 않습니다.)

대조 결과는 `inventory_v1.tsv` 의 `base_date`·`value_krw` 와도 맞춰 봅니다.
**inventory 값과 PDF 값이 다르면 PDF 가 우선**이며, 그 사실을 Step 9 로그의 `note` 에 남깁니다.

- `<h1>` 정확히 1개 / `<h2>` 3개 이상 / `<h3>` 1개 이상 (**v4 템플릿은 h2 8개**)
- JSON-LD 3블록 전부 파싱 / **FAQPage 질문 == 본문 `<h3>` 질문**
- `canonical` == `og:url` == `mainEntityOfPage.@id`
- 미치환 토큰 0건 / 숨김 키워드 스팬 0건
- 수수료·비용 금액 표현 0건 / 인명 패턴 0건 / `<\!--` 오타 0건
- `meta.tsv` 사이드카 존재 + 12개 키

**검증기가 아직 막지 않는 항목은 Step 4-Z 스윕으로 직접 확인합니다.**

- 담당 감정평가사 성명 / `"@type": "Person"` / `hasCredential` / 본건 동(棟) 번호 / 실제 층·호 숫자 /
  비교사례 동 번호 / 가치형성요인 / `역산` / 도로명주소 — **전부 0건**
- **`사정보정` 0건 · `시점수정` 0건 · 지수명 0건 · 산정과정 섹션 안의 비교사례 단가 0건** (규칙 B)
- **`publish-date` · `modified-date` · `report-date` 각 1건 이상, 다섯 군데 값 일치** (규칙 A)
- 텍스트 분량 5,000자 이하

템플릿·필드정의를 손댔다면 정합성도 확인합니다.

```bash
python3 automation/verify_template_v3.py \
  templates/case_template_v4.html templates/필드정의_v3.tsv
```

**오류(✗)가 1건이라도 남으면 초안을 넘기지 않습니다.** 고쳐서 0건이 될 때까지 반복합니다.
고칠 수 없으면 `automation/rejected/` 로 옮기고 사유를 남긴 뒤 사용자에게 보고합니다.

## 9-2. inventory 상태 갱신

해당 `seq` 행의 **10번 컬럼**을 `PENDING` → `DRAFTED` 로 바꿉니다.

```bash
python3 - <<'PY'
import io
SEQ="1"
p="/".join([__import__("os").environ["HOME"],"mnt","gaachi-website",
            "automation","sources","inventory_v1.tsv"])
lines=io.open(p,encoding="utf-8").read().split("\n")
hit=0
for i,ln in enumerate(lines):
    c=ln.split("\t")
    if len(c)>=12 and c[0]==SEQ and c[9]=="PENDING":
        c[9]="DRAFTED"; lines[i]="\t".join(c); hit+=1
assert hit==1, "치환 대상이 %d행입니다(1행이어야 함). 중단합니다." % hit
io.open(p,"w",encoding="utf-8",newline="").write("\n".join(lines))
print("inventory seq=%s -> DRAFTED" % SEQ)
PY
```

# 금지사항 (하나라도 어기면 게시가 거부되거나 사고가 됩니다)

1. **담당 감정평가사·의뢰인·소유자·신청인 성명을 쓰지 않습니다.** JSON-LD `author` 는 Organization 입니다.
2. **본건의 동(棟) 번호를 쓰지 않습니다.** 층·호는 **마스킹 기호(`제█층` · `███호`)로만** 표기하고 실제 숫자는 쓰지 않습니다.
3. **기준시점·거래시점에 월·일을 쓰지 않습니다.** 연도만 씁니다.
4. **가치형성요인 표·요인치를 싣지 않습니다.**
5. **사정보정치·시점수정률·시점수정 지수명·비교사례단가에서 결정단가로 가는 과정을 싣지 않습니다.**
   산식은 `결정단가 × 면적 = 산출금액 → 감정평가액` 까지입니다. (v4 규칙 B)
6. **게시일·최종 업데이트·감정평가서 작성일의 라벨과 class 를 섞지 않습니다.**
   초안의 게시일·최종 업데이트는 **오늘(KST)** 이며, 다섯 군데 값이 모두 같아야 합니다. (v4 규칙 A)
7. **소급감정을 시사하는 문구를 쓰지 않습니다.**
8. **수수료·평가비용 금액을 절대 쓰지 않습니다.**
9. **감정평가액이 공시가격보다 낮다는 취지로 쓰지 않습니다.**
10. **상속·증여 평가기간을 정확히 씁니다.** 상속 = 전 6개월 ~ 후 6개월, 증여 = 전 6개월 ~ 후 3개월.
11. **추측한 숫자를 절대 쓰지 않습니다.** 확정하지 못한 값은 블록째 빼고 로그 `note` 에 남깁니다.
12. **검증하지 않은 법령 조문 번호를 인용하지 않습니다**(`작성가이드_v4.md` §6 표 안에서만).
13. **기존 파일을 삭제하거나 수정하지 않습니다.** 재작성 시에는 `.bak-<버전>-<YYYYMMDD>` 로 복사 보존합니다.
14. **git 을 실행하지 않습니다.**
15. **`.json` 파일을 만들지 않습니다.**
16. **하루 1건을 넘겨 만들지 않습니다.**
17. **존재하지 않는 `/cases/*.html` 링크를 넣지 않습니다.**
18. **`<\!--` 오타를 쓰지 않습니다.**
19. **숨김 텍스트를 넣지 않습니다.**
20. **도로명주소를 쓰지 않습니다**(법인 본사 주소는 예외).
