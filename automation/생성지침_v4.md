# Step 1 — 대상 선정

`automation/sources/inventory_v1.tsv` 컬럼 순서(1-base):
```
1 seq  2 file_id  3 purpose  4 region  5 dong  6 prop_type
7 base_date  8 value_krw  9 methods  10 status  11 src_path  12 notes
```
→ `status` 는 **10번**, `notes` 는 **12번**입니다.

**선정 규칙**: `status == PENDING` 이고 `notes` 에 `부적합`/`UNSUITABLE` 이 없는 행 중 `seq` 가 작은 것부터.

```bash
awk -F'\t' 'NR>1 && $10=="PENDING" && $12 !~ /부적합/ && $12 !~ /UNSUITABLE/ {print $1"|"$2"|"$4" "$5"|"$6"|"$3"|"$8}' \
  "$HOME/mnt/gaachi-website/automation/sources/inventory_v1.tsv" | head -20
```

**적합성 판단 (중요)**: 규칙 B의 산식은 `결정단가 × 면적` **두 항뿐**입니다. 따라서
- ✅ **집합건물(아파트·오피스텔·구분상가)** — 전유면적 × 결정단가 하나로 끝나므로 가장 적합
- ⚠️ 토지+건물 복합(근생·다가구·단독주택) — 토지·건물을 나눠 평가하면 `CALC_GROUP2`(건물 원가법)를 써야 함. 가능하지만 신중히
- ❌ **다필지 토지+건물 복합**(예: seq1 김해 주촌면 15필지) — 단일 산식이 성립하지 않아 **건너뜀**. 로그에 사유를 남기고 PENDING 유지

seq 순서를 기계적으로 따르지 말고, **위 적합성 기준으로 건너뛴 건은 로그에 사유를 남기십시오.**

- `notes` 에 `미추출:` 이 있으면 PDF에서 직접 확인해야 하는 값입니다. 확인 불가면 **중단하고 보고**하십시오.

# Step 2 — PDF 판독 (숫자 확정)

**원본 PDF는 전부 스캔 이미지입니다. 텍스트 레이어가 없어 `pdftotext` 는 빈 결과를 냅니다.**

## 2-A. 권장 경로 — 페이지 이미지를 눈으로 읽기 ★
1. `mcp__remote-devices__device_stage_files` 로 PDF를 컨테이너(`/mnt/user-data/uploads/...`)에 올립니다.
2. 컨테이너 `Bash` 에서 PNG로 변환합니다.
   ```bash
   pdftoppm -r 150 -f 1 -l 12 -png "<PDF경로>" /tmp/p/a
   ```
3. **`Read` 툴로 PNG를 직접 보고** 숫자를 한 자리씩 대조합니다. OCR 결과는 숫자 확정용으로 쓰지 않습니다.

## 2-B. 반드시 확인할 값 (예외 없음)
- 최종 감정평가액 (원 단위 전액)
- **총괄표 확인** — 감정서 1건에 물건이 2개 이상인 경우가 흔합니다. `inventory` 의 `value_krw` 가 **합계**이고 본건은 그 일부일 수 있습니다. 반드시 총괄표에서 본건 금액을 분리하십시오.
- 기준시점 (연도만 게재하지만 평가기간 판단을 위해 날짜까지 읽음)
- **감정평가서 작성일** (표지·감정평가표 기재일 — 월·일까지 게재)
- 전유면적 / 주거공용면적 / 합계면적 / 소유권대지권면적 (집합건물), 또는 토지면적 / 건물 연면적
- **결정단가(산정단가)** (원/㎡) — 산정과정에 싣는 유일한 단가
- **산출금액** (결정단가 × 면적) — 감정서의 「시산가액」 표에 인쇄되어 있습니다. **직접 계산한 값이 아니라 감정서에 인쇄된 값을 쓰십시오.**
- 사용승인일, 용도지역, 지목, 주구조, 주용도, 단지규모
- 비교사례(감정평가전례·거래사례) 표 전체와 채택 사례
- 인근 거래가격수준(레인지)

**곱셈은 반드시 검산하십시오.** 검산값과 감정서 인쇄값이 다르면 **감정서 인쇄값을 쓰고** 로그에 남기십시오.

**사정보정치·시점수정률은 규칙 B로 게재하지 않으므로 초안에 옮기지 않습니다.** (결정단가가 제대로 읽혔는지 교차 확인용으로만 봅니다.)

`inventory` 값과 PDF 값이 다르면 **PDF가 우선**이며, 그 사실을 Step 9 로그 `note` 에 남깁니다.
소재지가 문서 안에서 엇갈리면(예: 서술부 vs 확정표) **「대상물건의 확정」 표를 정본**으로 삼고 로그에 남기십시오.

승인 대기 중이면 **`automation\승인_v1.bat` 을 실행해 검토·승인하면 된다**고 안내하십시오.

**중단했을 때** — 무엇을 왜 중단했는지와 사용자가 무엇을 해 주면 되는지를 한 문장으로.

# 금지사항 (하나라도 어기면 게시 거부 또는 사고)

1. 담당 감정평가사·의뢰인·소유자·신청인 **성명 기재** (JSON-LD `author` 는 Organization)
2. 본건 **동(棟) 번호** 기재 / 층·호 **실제 숫자** 기재
3. 기준시점·거래시점에 **월·일** 기재
4. **가치형성요인 표·요인치** 게재
5. **사정보정치·시점수정률·지수명·비교사례단가→결정단가 유도과정** 게재 (규칙 B)
6. 게시일·최종 업데이트·감정평가서 작성일의 **라벨·class 혼용** (규칙 A)
7. **소급감정 시사 문구**
8. **수수료·평가비용 금액**
9. 감정평가액이 **공시가격보다 낮다**는 취지
10. 상속·증여 **평가기간 오기** (상속 전후 6개월 / 증여 전 6개월·후 3개월)
11. **추측한 숫자** — 확정 못 한 값은 블록째 빼고 로그에 남김
12. 검증하지 않은 **법령 조문 번호** 인용
13. 기존 파일 **삭제·수정** (재작성 시 `.bak` 복사 보존)
14. **git 실행**
15. **`.json` 파일 생성**
16. Step 0 의 **생성 건수 규칙 초과**
17. 존재하지 않는 `/cases/<slug>` 링크
18. `<\!--` 오타
19. **숨김 텍스트**
20. **도로명주소** (법인 본사 예외)
21. **`.html` 붙은 URL** ← v4 신설
22. **`aggregateRating`·`review`·`Product`·`Offer`·`speakable` 스키마** ← v4 신설
23. **검증 불가능한 실적 주장**("100% 채택률" 등) ← v4 신설
