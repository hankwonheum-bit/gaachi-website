#           최소한으로 차단합니다.

# ※ 중요 ※ Cloudflare 대시보드의 "Managed robots.txt"(AI 학습 차단) 기능이

#   / CCBot / Applebot-Extended / meta-externalagent / Amazonbot / Bytespider
#   에 대한 "Disallow: /" 블록을 자동 주입하여 아래 설정을 무력화합니다.
